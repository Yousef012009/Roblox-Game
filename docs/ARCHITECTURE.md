# Concentration 64: Technical Architecture

PS1 retro-noir detective word game for Roblox. Everything, including the 3D map, is generated by Luau inside Roblox Studio. There is no Blender and no imported assets except the music `SoundId` you upload.

## 1. Runtime overview

```
                 ┌──────────────── SERVER (authoritative) ────────────────┐
 MapGenerator ──►│ Workspace.Map (lobby + 4 queue elevators)               │
 (Script)        │ ServerStorage.InterrogationModuleTemplate               │
                 │                                                          │
 GameManager ───►│ QueueService ── spatial scan (0.2 s) ──► 4 queues        │
 (Script)        │      │ full queue + free room slot                      │
                 │      ▼                                                    │
                 │ MatchService ── slot pool ──► Match (one per room)       │
                 │      Match: state machine, RoomController, TextFilter    │
                 └───────────────┬──────────────────────────────────────────┘
          MatchSnapshot / MatchEvent (to that match's players only)
          QueueStatus (everyone) · InputRejected · Notify
                                 │  ▲ SubmitCategory / SubmitAnswer / JudgeAnswer / LeaveQueue / GetState
                 ┌───────────────▼──┴───────────────────────────────────────┐
 ClientManager ─►│ snapshot mirror → UI screens, MusicController, RoomFX,   │
 (LocalScript)   │ CameraController, LobbyFX                                 │
                 └───────────────────────────────────────────────────────────┘
```

* **Server owns every decision**: queue membership, match start, Caller, category, turn order, deadlines, repeats, eliminations, winners.
* **Clients render**: they draw everything from the latest `MatchSnapshot` plus the shared clock `Workspace:GetServerTimeNow()`.
* **Music time**: a match broadcasts `musicStartTime` (server clock of song position 0). `ReplicatedStorage.Shared.MusicTimeline` converts `now - musicStartTime` into beats. Turn deadlines are beat times computed by the same module on the server.

## 3. Geometry contract (studs; Roblox Y-up)

* All floors have their **top surface at Y = 0.2**, so they never z-fight the Baseplate at Y = 0.
* **Lobby**: footprint X ∈ [-70, 70], Z ∈ [-60, 60], ceiling about 34. Spawn area at the front (Z ≈ +40). Back wall at Z = -60.
* **Queue elevators**: four chambers recessed behind the back wall, centred at X = -45, -15, 15, 45, interior about 11 × 11 × 12. Door opening faces +Z into the lobby. `QueueNN_Trigger` covers the interior floor area (height about 8). `QueueNN_Exit` sits about 6 studs in front of the door, inside the lobby. `QueueNN_Spot1..4` are the four standing marks.
* **Interrogation module** (template pivot = module origin). Slot 0 is placed at `Config.Match.RoomOrigin` = (100, 0, 0). Slot *k* is offset along Z by `RoomSpacing` (320), alternating + and −.
  * Interrogation room interior: X ∈ [-14, 14], Z ∈ [-12, 12], height 14.
  * Two-way mirror in the wall at X = +14.5: opening Z ∈ [-9, 9], Y ∈ [3, 11].
  * Spectator lounge interior: X ∈ [15, 29], Z ∈ [-12, 12] (behind the mirror).
  * TV on the X = -14 wall, Front face toward +X, centre about Y = 8.
  * Table at the room centre. **SeatAnchor01** north (Z ≈ -5.5, facing +Z), **02** east (X ≈ +7, facing -X), **03** south (Z ≈ +5.5, facing -Z), **04** west (X ≈ -7, facing +X). That is clockwise from above, so "to my left" is the next seat number.
  * BulbPivot at the ceiling above the table (Y ≈ 13.6). The bulb hangs about 5 studs below it.
  * InterrogationCamera: high, on the mirror side, looking at the table and TV. SpectatorCamera: in the lounge, looking through the mirror at the same subject.
  * Module total X span [-15, 30] → world X 85…130. It never overlaps the lobby (X ≤ 70).

## 4. Match state machine

```
QUEUEING (QueueService) ──4 players + free slot──► INTRO
INTRO ──IntroSeconds──► CALLER_SELECTION ──CallerRevealSeconds──► CATEGORY_SELECTION
CATEGORY_SELECTION ──Caller submits (or timeout → fallback)──► COUNTDOWN
COUNTDOWN (music starts; chant 16 beats; sting reveals category) ──beat 20──► PLAYING
PLAYING ──answer arrives, not a repeat──► JUDGING ──VALID──► PLAYING
        │                                         └─WRONG──► ELIMINATION
        ├──repeat of an accepted answer──────────────────► ELIMINATION
        ├──deadline passes (hesitation)──────────────────► ELIMINATION
        └──answerer leaves───────────────────────────────► ELIMINATION
ELIMINATION ──EliminationSeconds──► PLAYING   (≥2 answerers left)
                                └─► ROUND_END (1 answerer left → round winner)
ROUND_END ──more rounds & ≥3 players──► CALLER_SELECTION (Caller rotates; eliminated return to seats)
          └─otherwise──► GAME_END ──GameEndSeconds──► CLEANUP (teleport to lobby, destroy room, free slot)
Any state ──connected players < MinPlayersToContinue──► GAME_END (or CLEANUP if nobody is left)
```

Race-free by construction: each `Match` runs one coroutine that owns its state. Remote handlers only validate and record input (`turn.submission`, `judging.verdict`). The loop consumes them. Every transition bumps `version`. Every turn has a unique `turnId`, and a request carrying a stale `matchId` or `turnId` is ignored. An answer that is being filtered (yielding) holds the deadline until the check finishes, and the turn identity is re-checked afterwards.

## 5. Rules and policies

| Situation | Policy |
|---|---|
| Caller | random in round 1, then rotates through seats so everyone calls once (`RoundsPerMatch = 0`) |
| Turn order | answerers in seat order starting LEFT of the Caller, skipping eliminated players |
| Turn length | `MusicTimeline.beatsPerTurn()` beats, starts and ends on a beat; latency grace 0.3 s on arrival |
| Blank / too long / censored answer | `InputRejected`; timer keeps running; may retry |
| Repeat of an accepted answer (this round) | automatic elimination; the Caller cannot override |
| Caller presses VALID / GIBBERISH | VALID records the answer; GIBBERISH eliminates |
| Caller doesn't judge in time | answer **accepted** (never assumed wrong) + JudgeTimeout notice; after 2 in a row the round switches to auto-judge |
| Caller leaves | pending answer accepted; auto-judge for the rest of the round; the next round picks a new Caller |
| Text filter fails (twice) | answer: the turn is voided (no elimination). Category: a fallback category from Config |
| Player leaves mid-turn / mid-match | eliminated as "Left"; play continues if ≥ 3 remain, otherwise GAME_END |
| Respawn during a match | re-seated (active) or returned to the lounge (eliminated) |
| Winner | most round wins → most accepted answers → shared win |

## 6. Client presentation by state

| State | Answerer | Caller | Spectator (eliminated) |
|---|---|---|---|
| INTRO | intro overlay, IntroCamera → InterrogationCamera | same | — |
| CALLER_SELECTION | "X IS THE CALLER" | "YOU ARE THE CALLER" | same |
| CATEGORY_SELECTION | waiting card | category text box | waiting card |
| COUNTDOWN | metronome, chant text, music, bulb swing; sting = category reveal | same | same |
| PLAYING | HUD (category, current answerer, order, timer), answer box on own turn | HUD | spectator HUD + cameras |
| JUDGING | "CALLER IS JUDGING" | VALID / GIBBERISH panel | sees answer on TV |
| ELIMINATION | red pulse; ELIMINATED overlay for the victim | same | same |
| ROUND_END / GAME_END | round winner / victory screen, VictoryCamera | same | same |
| CLEANUP | back to lobby camera and controls | same | same |
